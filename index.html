กำหนดรหัสผ่านสำหรับเข้าสู่ระบบ

คู่มือการใช้งานระบบนัดคิวทำงาน v2.7.0

1. การเข้าสู่ระบบและการแยกสิทธิ์ผู้ใช้งาน (ADMIN / STAFF)

ระบบบันทึกชัดเจนว่า ใครเป็นคนสร้างนัด, ใครเป็นคนกดยกเลิก/เสร็จสิ้น และ ใครแก้ไขล่าสุด:

  • บัญชีเริ่มต้น: admin (รหัสผ่าน admin), somchai (รหัสผ่าน 1234), wipada (รหัสผ่าน 1234)
  • สิทธิ์การใช้งาน: สมาชิกระดับ STAFF สามารถดูและจัดการนัดหมายได้เฉพาะหน้า "ปฏิทินเดือน" ส่วนระดับ ADMIN เข้าถึงได้ครบทุกหน้าและจัดการสมาชิกได้
  • ฟีเจอร์ลัดบนการ์ด: สามารถกดปุ่ม คัดลอกนัด เพื่อสร้างนัดซ้ำ, คัดลอกข้อความ เพื่อส่งต่อทางแชท, หรือ .ics เพื่อบันทึกเข้าแอปปฏิทินมือถือได้ทันที (คีย์ลัด Alt+N สร้างนัดใหม่, Esc ปิดหน้าต่าง)

2. การเชื่อมต่อฐานข้อมูล Google Sheets

เมื่อต้องการซิงก์ข้อมูลจริงร่วมกันในทีม ให้ไปที่แท็บ "ตั้งค่า / บอท" กรอก Web App URL และรหัสผ่านทีม แล้วกดปุ่ม "บันทึกและเชื่อมต่อ"

3. คำสั่งถามตารางงานผ่านแชทกลุ่ม LINE (ฟรี ไม่เสียโควตา)

4. การแจ้งเตือนผ่านเว็บ (Web Push) และการติดตั้งแอปลงเครื่อง (PWA)

  • เปิดรับการแจ้งเตือนบนอุปกรณ์: กดปุ่ม แจ้งเตือนเว็บ บนแถบด้านบน (หรือไปที่แท็บ ตั้งค่า / บอท) แล้วกด อนุญาต (Allow) เมื่อเบราว์เซอร์สอบถาม ระบบจะแจ้งเตือนนัดหมายและอัปเดตของทีมโดยไม่หักโควตา LINE
  • ติดตั้งบนคอมพิวเตอร์ / Android: กดปุ่ม ติดตั้งแอป บนแถบด้านบน หรือกดปุ่มติดตั้งบนแถบ URL ของเบราว์เซอร์ Chrome / Edge เพื่อเปิดใช้งานแบบเต็มหน้าจอเสมือนแอปพลิเคชัน
  • ติดตั้งบน iPhone / iPad (Safari): แตะปุ่ม แชร์ (Share) ด้านล่าง แล้วเลือก เพิ่มไปยังหน้าจอโฮม (Add to Home Screen)
