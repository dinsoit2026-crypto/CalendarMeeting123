# Calendar & Appointment Management System (v2.1.0)

ระบบบริหารจัดการคิวนัดหมายและแจ้งเตือนผ่าน LINE สำหรับทีมงาน พร้อมสรุปสถิติท้ายปี (รองรับการใช้งานผ่านเว็บบนมือถือและคอมพิวเตอร์)

## คุณสมบัติเด่น (Features)
- บันทึกคิวนัดหมายงานประจำวัน เลื่อนวัน/เวลา สถานที่ และบุคคลที่นัดพบ
- จัดการสถานะ 3 ระดับ: นัดหมายแล้ว, สิ้นสุดการนัดหมาย, ยกเลิกการนัดหมาย
- ระบบสรุปสถิติประจำปี (Year-End Overview): สรุปงานทั้งหมด, รอพบ, สิ้นสุด (พร้อมคำนวณร้อยละความสำเร็จ), ยกเลิก (พร้อมคำนวณร้อยละการยกเลิก) และสถิติการเลื่อนนัด
- การแจ้งเตือนผ่าน LINE อัตโนมัติ: สรุปงานรอบเช้า (Daily Digest เวลา 08:00 น.) และเตือนก่อนนัดหมาย 1 ชั่วโมง (Hourly Alert)
- สอบถามคิวงานผ่านกลุ่ม LINE แบบโต้ตอบได้ทันที (ใช้ Reply API ฟรี ไม่กระทบโควตาข้อความ Push รายเดือน)
- รองรับการใช้งานพร้อมกันหลายคนผ่านฐานข้อมูล Google Sheets

## โครงสร้างโปรเจกต์
- `index.html` - หน้าเว็บแอปพลิเคชัน (Web UI)
- `style.css` - สไตล์การแสดงผลแบบ Slim Card กระชับสูง และรองรับ Responsive มือถือ
- `app.js` - ตัวควบคุมหน้าเว็บและเชื่อมต่อ Google Apps Script API
- `logic.js` - ฟังก์ชันคำนวณวันเวลา (Asia/Bangkok), ตรวจสอบความถูกต้อง, ระบบแจ้งเตือน และสรุปสถิติ
- `patchnotes.js` - บันทึกประวัติการพัฒนาและฟีเจอร์แต่ละเวอร์ชัน
- `tests.js` / `tests.html` - ชุดทดสอบอัตโนมัติ 14 รายการ
- `SETUP_GUIDE.md` - คู่มือการติดตั้งระบบ LINE Messaging API และ Google Sheets
- `gas/Code.gs` - โค้ดฝั่งเซิร์ฟเวอร์ Google Apps Script
- `gas/appsscript.json` - ค่าคอนฟิกโปรเจกต์ Apps Script

## นโยบายระบบ (System Policy)
- Zero-Emoji Policy: ไม่อนุญาตให้ใช้อิโมจิในทุกส่วนของระบบ (โค้ด, ข้อความในระบบ, ข้อความใน LINE และหน้าเว็บ)
- Timezone: Asia/Bangkok (UTC+07:00) รองรับทั้งปี พ.ศ. และ ค.ศ.
