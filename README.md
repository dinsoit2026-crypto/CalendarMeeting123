# Calendar & Appointment Management System (v2.4.0)

ระบบบริหารจัดการคิวนัดหมายและแจ้งเตือนผ่าน LINE สำหรับทีมงาน พร้อมสรุปสถิติท้ายปี ธีมสีน้ำเงิน-ส้ม (Ocean Blue & Energetic Orange) และระบบ Smart Auto-Trigger (รองรับการใช้งานผ่านเว็บบนมือถือและคอมพิวเตอร์)

## คุณสมบัติเด่น (Features)
- บันทึกคิวนัดหมายงานประจำวัน เลื่อนวัน/เวลา สถานที่ และบุคคลที่นัดพบ
- จัดการสถานะ 3 ระดับ: นัดหมายแล้ว, สิ้นสุดการนัดหมาย, ยกเลิกการนัดหมาย พร้อมแจ้งเตือน LINE อัตโนมัติเมื่อสิ้นสุดหรือยกเลิก
- ระบบสรุปสถิติประจำปี (Year-End Overview): สรุปงานทั้งหมด, รอพบ, สิ้นสุด (พร้อมคำนวณร้อยละความสำเร็จ), ยกเลิก (พร้อมคำนวณร้อยละการยกเลิก) และสถิติการเลื่อนนัด
- การแจ้งเตือนผ่าน LINE อัตโนมัติ: ระบบ Smart Auto-Trigger ตั้งเวลาปลุกเตือนตามเวลานัดหมายจริง, สรุปงานรอบเช้า (Daily Digest เวลา 08:00 น.) และเตือนก่อนเวลานัดหมาย (Hourly Reminder)
- สอบถามคิวงานผ่านกลุ่ม LINE แบบโต้ตอบได้ทันที (ใช้ Reply API ฟรี ไม่กระทบโควตาข้อความ Push รายเดือน)
- รองรับการใช้งานพร้อมกันหลายคนผ่านฐานข้อมูล Google Sheets
- ปรับขนาด UI ให้อ่านง่าย ชัดเจน พร้อมโหมดมืด (Dark Mode โทน Deep Navy)

## โครงสร้างโปรเจกต์
- `index.html` - หน้าเว็บแอปพลิเคชัน (Web UI v2.4.0)
- `style.css` - สไตล์การแสดงผลแบบ Modern SaaS ธีม Ocean Blue & Energetic Orange
- `app.js` - ตัวควบคุมหน้าเว็บและเชื่อมต่อ Google Apps Script API
- `logic.js` - ฟังก์ชันคำนวณวันเวลา (Asia/Bangkok), ตรวจสอบความถูกต้อง, ระบบแจ้งเตือน และสรุปสถิติ
- `patchnotes.js` / `CHANGELOG.md` - บันทึกประวัติการพัฒนาและฟีเจอร์แต่ละเวอร์ชัน
- `tests.js` / `tests.html` - ชุดทดสอบอัตโนมัติ 16 รายการ
- `SETUP_GUIDE.md` - คู่มือการติดตั้งระบบ LINE Messaging API และ Google Sheets
- `gas/Code.gs` - โค้ดฝั่งเซิร์ฟเวอร์ Google Apps Script (v2.4.0)
- `gas/appsscript.json` - ค่าคอนฟิกโปรเจกต์ Apps Script
